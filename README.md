# Svitio s.r.o. Brand Assets

Welcome to the official **Svitio s.r.o. brand assets repository**.  
This repository contains logos and related visual assets for use in approved company materials.

All logos are the property of **Svitio s.r.o.** and may only be used according to the guidelines below.

## Logo Usage Guidelines

To maintain the integrity of the **Svitio brand**, please follow these rules:

- **Do not modify** the logos (colors, proportions, or design).
- **Do not combine** the logos with other graphics or text without permission.
- Use logos **only in materials representing Svitio s.r.o.**
- Preferred formats: PNG or SVG, depending on context.
